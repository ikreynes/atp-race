# 🎾 ATP Race

Simulador de carrera de tenis. Arrancás a los 15 años, jugás temporadas hasta
el retiro (máximo 40), progresás de nivel, subís en el ranking ATP, ganás
torneos, plata y fama.

HTML + CSS + JS vanilla, sin librerías externas ni build. Se juega abriendo
`index.html` (o desde GitHub Pages).

## Estructura

- `index.html` — esqueleto de la página.
- `styles.css` — todo el CSS.
- `data.js` — datos base (países, torneos, tienda, logros, etc).
- `game.js` — estado del juego y toda la lógica.

## Jugar localmente

Abrí `index.html` en el navegador. No hace falta servidor ni instalar nada.
